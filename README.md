# 當 AI 什麼都能做，我們還能靠什麼創造財富？

Toastmasters「創富」30 分鐘專題演講網頁簡報。

副標題：**AI 時代，最值錢的是把想法變成結果的人**

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可。若瀏覽器限制本機功能，也可以在此資料夾執行：

```bash
python3 -m http.server 4179 --bind 127.0.0.1
```

再開啟：<http://127.0.0.1:4179/index.html>

## 操作

- `→`／`Space`／`PageDown`：逐步顯示內容；本頁完成後進入下一頁
- `←`／`PageUp`：逐步收回內容；本頁收完後回到上一頁
- `Home`／`End`：第一頁／最後一頁
- `O`：投影片總覽
- `F`：進入或離開全螢幕
- `P`：列印或另存 PDF
- `Esc`：關閉總覽或離開全螢幕

簡報會記住目前頁次；重新開啟後會回到上次位置。

## 內容結構

1. 先從增加收入的可能方式，整理出人力、金錢與系統三種放大機制
2. 從《三國萌將守城》到《英雄演義》：改版演進與 60 秒作品介紹
3. 從願望到作品：說清楚、拆小、AI 協作、驗證
4. 東海課堂專題：從沒人想參賽，到 Team ROSC 榮獲金獎
5. 從遊戲連到 N-Ticket：相同的整合與實作能力
6. N-Ticket：把「誰在什麼時候做什麼」轉成變更工單與自動排程
7. 未來最吃香的四種能力
8. 人力、金錢、系統三種槓桿，以及 AI 對數位人力、算力資源與智慧自動化的延伸
9. AI 作為系統槓桿加速器
10. Toastmasters 的表達與整合優勢
11. 三個行動問題與故事回扣
