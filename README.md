# 當 AI 什麼都能做，我們還能靠什麼創造財富？

Toastmasters「創富」30 分鐘專題演講網頁簡報。

副標題：**AI 時代，最值錢的是把想法變成結果的人**

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可。若瀏覽器限制本機功能，也可以在此資料夾執行：

```bash
python3 -m http.server 4179 --bind 127.0.0.1
```

再開啟：<http://127.0.0.1:4179/index.html>

## 操作

- `→`／`Space`／`PageDown`：下一頁
- `←`／`PageUp`：上一頁
- `Home`／`End`：第一頁／最後一頁
- `O`：投影片總覽
- `F`：進入或離開全螢幕
- `P`：列印或另存 PDF
- `Esc`：關閉總覽或離開全螢幕

簡報會記住目前頁次；重新開啟後會回到上次位置。

## 內容結構

1. 《三國萌將守城》故事：吸引注意力
2. 從願望到作品：說清楚、拆小、AI 協作、驗證
3. 從遊戲連到 N-Ticket：相同的整合與實作能力
4. ISO 遠端工作變更：文件與制度連動案例
5. 未來最吃香的四種能力
6. 人力、金錢、軟體三種槓桿
7. AI 作為軟體槓桿加速器
8. Toastmasters 的表達與整合優勢
9. 三個行動問題與故事回扣
